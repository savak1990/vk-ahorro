# Use cases

The use case model of Ahorro. The diagram [`use-cases.puml`](use-cases.puml) is the table of contents; each file holds the text. Milestones list the use cases they deliver; feature specs in `specs/` cite the use case they implement.

Rules that several use cases share are defined once in [`shared-rules.md`](shared-rules.md) and cited by ID (`SR-n`).

Maintained with the `ahorro-use-cases` skill. IDs are stable and never reused.
