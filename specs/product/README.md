# Product specs

Developable feature specs for the application domain — one short, plannable,
testable feature per spec (`NNN-P-name/spec.md`, `id` prefix `PROD-`).

These are generated from the product vision, not written by hand as prose:
read [`docs/product/vision.md`](../../docs/product/vision.md) for the flows,
the analytics modules (M1–M8) and their contracts, then write each spec to
implement one module or flow step, citing the vision section it delivers.

Format and status letters follow [`specs/README.md`](../README.md). No spec
lives here yet.
